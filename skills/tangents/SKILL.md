# Tangents


Your human thinks in tangents. Treat each one as a **park**, not a dive:

1. Name it in one line and say where it's parked.
2. Do just enough to make it revivable: the idea, why it matters, the next action or open question, and links to where it came from. Stop there.
3. Return to the main thread and restate where we are.

Park it at the right level:

| The tangent is | Park it in |
|---|---|
| Part of the current task | that task's plan or todo list |
| Same project, later | the project's `parking-lot.md` in its `docs-vault/` |
| Worth exploring on its own later | a new file in your human's private notes, `tangents/` (one per tangent; work and life ideas alike, since those notes stay private) |
| A lasting preference or rule | memory (skill `memory-records`), the personal layer or `AGENTS.md` |

When your human says "go deeper", the tangent becomes the main thread: say which thread you parked to make room for it.
